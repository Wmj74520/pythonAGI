# 个人学习记录管理器

一个用 Python 写的命令行小工具，用来记录每天的学习内容。数据保存在 `records.json` 里，关掉程序再打开，记录还在。

## 功能

- 添加学习记录（日期 + 内容）
- 查看所有记录
- 删除某条记录
- 修改某条记录
- 按关键词搜索记录
- 日期格式校验（必须是 `YYYY-MM-DD`，且是真实存在的日期）

## 运行方法

### 1. 准备环境

需要 Python 3.10 或以上。在本文件夹里创建并激活虚拟环境：

```
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 2. 安装依赖

```
pip install -r requirements.txt
```

### 3. 启动程序

```
python 学习记录管理器.py
```

然后按屏幕提示输入 `1`～`6` 选择功能。

## 运行测试

```
pytest
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `学习记录管理器.py` | 主程序 |
| `records.json` | 保存所有记录的数据文件（首次运行自动生成） |
| `test_学习记录管理器.py` | 项目的自动化测试 |
| `requirements.txt` | 依赖清单 |
| `.gitignore` | 告诉 Git 哪些文件不用提交 |

## 数据格式

`records.json` 里是一个列表，每条记录长这样：

```json
{
  "date": "2026-11-20",
  "content": "今天学了 Python 的类和对象"
}
```
